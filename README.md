本目录是一个**纯静态网站**，可直接托管到 GitHub Pages、Netlify、Vercel、任意静态空间，无需服务器。

## 包含的九大测算
八字算命、称骨算命、周易算命、八字运程、五行查询、九星论命、农历算命、鬼谷算命、生日算命。
全部基于浏览器端真实干支排盘引擎（js/bazi.js、js/lunar.js、js/fortunes*.js），无需后端。

## 本地预览
直接用浏览器打开 `index.html` 即可（无需 Node）。若需本地模拟后端调试，可运行 `node server.js`（仅本地用，线上不需要）。

## 部署到 GitHub Pages（免费、独立域名）
1. 到 https://github.com 用邮箱 807904997@qq.com 注册账号（免费）。
2. 验证邮箱（注册后会发验证码到你 QQ 邮箱）。
3. 新建仓库，名称建议 `tianji-ge`。
4. 把本目录**全部文件**（含 `.nojekyll`）上传到仓库。
5. 仓库 Settings → Pages → Source 选 `main` 分支 / `root` → Save。
6. 约 1 分钟后访问 `https://<你的用户名>.github.io/tianji-ge/` 即上线。

> 上线后请把真实用户名告知建站助手，以便把 `index.html`、`robots.txt`、`sitemap.xml` 里的 `YOURUSERNAME` 占位符替换为真实地址（影响 SEO）。

## 每日自动更新
- 资讯：本地自动化（每天 08:05）会联网搜命理热点、更新 8 条并保 16 条，写入 `js/news-data.js`。
- 推广：本地自动化（每天 09:30）生成 SEO 软文 + 合规引流文案草稿。
- 若要**线上站点也每天自动更新**，需把更新后的 `js/news-data.js` 重新推送仓库（可由建站助手用 GitHub Token 自动推送，需站长提供 Token）。
